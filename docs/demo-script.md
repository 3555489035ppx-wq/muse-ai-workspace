# Muse 3-Minute Demo Script

| Time | Action | What to say |
| --- | --- | --- |
| 00:00 | Open the landing page | Early design work loses time because the problem, evidence, and choices are split across tools. |
| 00:20 | Click **体验完整设计流程** | Muse begins with a featured case instead of asking the reviewer to choose between four unrelated projects. |
| 00:45 | Open the brief and research | The product turns a fuzzy request into a shared context with sources and limitations. |
| 01:20 | Compare directions | Direction cards expose opportunity, hypothesis, trade-off, and validation metric. |
| 02:00 | Open concept, CMF, and review | AI accelerates structure and candidates; the designer confirms what moves forward. |
| 02:35 | Open versions and decision map | The final value is explainability: what changed, why it changed, and what should be tested next. |
| 03:00 | Stop at the decision map | Muse is a decision workspace, not a chatbot that happens to generate images. |
